Gesture → Sound In progress

2026

  • Machine learning
  • TensorFlow
  • MobileNetV2
  • KNN

Overview

A creative classification tool built on MobileNet. I pull stills from music videos by an artist whose work uses hand gestures as a deliberate visual language, sort the frames by hand shape, and give each shape its own sound. When a new video plays, the model recognizes the hand shapes and triggers the matching sounds.

The goal is to explore the relationship between images, sound, and messaging in his work.

How it works

  1. Collect: pull stills from the artist's music videos.
  2. Label: sort the frames by hand shape into groups (for example sign, point, and L's), and assign each group a sound.
  3. Extract features: a pretrained MobileNetV2 (TensorFlow / Keras, in Google Colab) turns each frame into a set of features.
  4. Classify: a KNN classifier trained on those features recognizes hand shapes in new video.
  5. Play: each recognized shape triggers its sound as the video plays.

Prototype

An early browser prototype of where this is headed: I train three hand shapes live on my webcam, give each its own sound, and the classifier plays the matching sound with a confidence score.

Status

In progress. The finished tool will do this with stills from the artist's music videos instead of my webcam.
